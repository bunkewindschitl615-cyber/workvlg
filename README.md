# WORKVLG

Сайт строительной и ремонтной компании WORKVLG (Волгоград и Волгоградская область).

Стек: [Astro 7](https://docs.astro.build) + TypeScript (strict), Node-адаптер `@astrojs/node` в режиме `standalone`.
Страницы собираются в статический HTML; на Node-сервере выполняются только серверные маршруты (приём заявок — этап 7).

## Требования

- Node.js 26 LTS (минимум 22.23.4), npm 11+.

## Запуск

```powershell
npm install
Copy-Item .env.example .env   # затем заполнить значения
npm run dev                   # http://localhost:4321
```

| Команда | Назначение |
|---|---|
| `npm run dev` | Режим разработки с горячей перезагрузкой |
| `npm run check` | Проверка типов TypeScript и Astro-компонентов |
| `npm run build` | Проверка типов + production-сборка в `dist/` |
| `npm run preview` | Локальный просмотр production-сборки |
| `npm start` | Запуск production-сервера (`HOST`, `PORT` из окружения) |

## Конфигурация

Все настройки — в `.env` (образец с пояснениями: `.env.example`). Значения подставляются при сборке, поэтому после изменения `.env` нужно выполнить `npm run build` заново.

- **Контакты** (`PUBLIC_CONTACT_*`, `PUBLIC_*_URL`). Пустое значение — канал не показывается на сайте. Некорректный телефон или ссылка останавливают сборку с понятной ошибкой.
- **Instagram** выводится только при `PUBLIC_SHOW_INSTAGRAM=true` и всегда со сноской о статусе компании Meta в РФ.
- **Индексация** выключена по умолчанию (`PUBLIC_INDEXING=false`): `robots.txt` запрещает обход, на страницах стоит `noindex`. Включать только после наполнения сайта реальными данными.
- **`SITE_URL`** — публичный адрес сайта для canonical, sitemap и Open Graph.

Код конфигурации: `src/config/` (`site.ts` — общие данные, `contacts.ts` — каналы связи, `features.ts` — флаги функций).

## Структура

```
src/
  config/       централизованная конфигурация
  components/   компоненты (seo/ — метатеги)
  layouts/      шаблоны страниц
  pages/        маршруты: index, 404, robots.txt
  styles/       глобальные стили
public/         статические файлы
```
